# easySQL – Download

easySQL untersucht und optimiert Microsoft SQL Server Express auf dem Server selbst: Es sichert die Datenbanken, stellt Windows und SQL Server auf Leistung ein, pflegt Indizes und Statistiken und richtet auf Wunsch eine tägliche Wartung mit Datensicherung ein. Vorher lässt sich abschätzen, wie viel das bringen würde, ohne etwas zu ändern.

Hier liegt nur das fertige Programm, kein Quelltext.

## Start

- Eine einzelne Datei, keine Installation.
- Direkt auf dem SQL-Server starten. Startet mit Adminrechten (Windows fragt nach).
- Benötigt Windows 10/11 (64 Bit) mit WebView2, bei Windows 11 vorhanden.
- Am besten außerhalb der Arbeitszeit: Während der Optimierung sind Tabellen zeitweise gesperrt.
